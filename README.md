🌱 **E-LCAT (Enhanced Lightweight Color-Aware Transformer with Hierarchical Attention for Leaf Disease Classification in Precision Agriculture)** is a deep learning-based plant leaf disease classification system developed to support smart agriculture and precision farming. The proposed model enhances the traditional LCAT architecture by integrating **🎨 Color Attention**, **🔍 Multi-Scale Feature Extraction**, **⚙️ Squeeze-and-Excitation (SE) Blocks**, and **🧠 Hierarchical Attention Transformer (HAT)** modules. These components help the system accurately identify disease-specific symptoms such as lesions, discoloration, and texture abnormalities from leaf images while maintaining a lightweight computational design suitable for real-time agricultural applications.

💻 The proposed system is integrated with a **web-based application**, where users can easily upload a plant leaf image through a user-friendly interface and receive instant disease predictions, confidence scores, top prediction probabilities, and disease management recommendations. By introducing **🔗 Global Residual Connections** and channel-wise feature refinement, the proposed E-LCAT model achieved an accuracy of **83%**, outperforming the existing LCAT model (**75%**). This project contributes towards **🌾 Smart Agriculture**, **📱 AI-Based Crop Monitoring**, **☁️ Web-Enabled Disease Diagnosis**, and **🌍 Sustainable Farming Practices** by enabling early disease detection, reducing crop losses, and helping farmers make informed decisions in real time.
